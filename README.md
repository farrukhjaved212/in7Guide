# IN7 Guide

IN7 Guide is a lightweight Android application built with Flutter, designed to provide users with a simple and easy-to-use interface for accessing organized information, helpful guides, safety information, and app-related resources.

## Features

- **Home:** A simple and user-friendly home screen.
- **Explore:** Browse available guides and informational content.
- **Search:** Find information quickly.
- **Bookmarks:** Save useful articles for later access.
- **Safety:** Access safety-related information and guidance.
- **Native Flutter Interface:** Built with Flutter for a smooth mobile experience.

## Technology Stack

- Flutter
- Dart
- Android
- Shared Preferences
- URL Launcher

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android SDK
- Android Studio or Visual Studio Code

### Clone the Repository

```bash
git clone https://github.com/farrukhjaved212/in7Guide.git
```

### Navigate to the Project

```bash
cd in7Guide
```

### Install Dependencies

```bash
flutter pub get
```

### Run the Application

```bash
flutter run
```

### Build APK

```bash
flutter build apk --release
```

The generated APK will be available at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
